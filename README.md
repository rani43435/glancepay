# Glance Pay

Prototype web app for **Meta Ray-Ban Display**: look at a pay code, pinch to pay.
Payments are simulated — no real money moves.

- `index.html`, `style.css`, `app.js` — the app (600×600 display, focus navigation)
- `paycode.html` — generates a demo pay QR code to scan

Test in Chrome with the Meta Ray-Ban Display Simulator extension.
Arrow keys move focus, Enter presses, Esc goes back.
